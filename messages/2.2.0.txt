Google Spell Check 2.2.0
========================

Four commands now, named for what they do.

  Google Spell Check: Fix                  fix the spelling (this is the old command)
  Google Spell Check: Fix and Highlight    fix it, and mark what changed
  Google Spell Check: Highlight Only       mark what WOULD change, touch nothing
  Google Spell Check: Clear Highlights     remove the marks

Only the palette and menu captions changed on the original -- the command itself is
still "google_spell_check", so any key binding you already have keeps working.

Highlight Only.

It runs exactly the same lookups as Fix, but never edits your buffer. Each misspelled
word gets a squiggly underline, a gutter dot, and an inline annotation on the right
showing the correction it *would* have made -- so you can look before anything is
rewritten.

Only the misspelled words are marked, not everything you selected. Select a whole
paragraph and just the bad words get underlined.

This is for the case where you want to check a file that isn't prose. Running Fix over
code will happily "correct" identifiers like const or EN; Highlight Only shows you that
up front instead of rewriting the file.

Highlights are cleared by "Google Spell Check: Clear Highlights" (palette or
right-click), or by closing the annotations with the x at their right edge.

Fix and Highlight.

The middle ground: it makes the edits AND leaves every correction marked, so you can
see what it did. Unlike Fix it doesn't select anything, so the marks survive your next
keystroke.

The status bar lists the corrections.

All three commands name the words they changed rather than echoing the whole line back
at you:

  Google Spell Check: respecting, leadership

Words run together are now corrected.

"anotherone" -> "another one", "alot of people" -> "a lot of people". Google returns
more words than you typed for these, which used to be rejected outright as an extension
of your text rather than a correction of it. A run-together word and a typo beside it
are reported separately, too -- "anotherone bites the dustr" lists "another one, dust".

Corrected words are now selected.

The Fix command leaves every word it corrected selected, so you can see at a glance what
changed. Type to replace it, or just click anywhere to dismiss. With several selections
at once you get one selection per correction.

The example key bindings cover all three:

  Preferences > Package Settings > Google Spell Check > Example Key Bindings

  { "keys": ["ctrl+alt+g"], "command": "google_spell_check" },
  { "keys": ["ctrl+alt+shift+g"], "command": "google_spell_check_fix_highlight" },
  { "keys": ["ctrl+alt+h"], "command": "google_spell_check_highlight" },
